# 1.1.1 / build 5：DMG 安装包与 GitHub 发布

日期：2026-11-08。用户明确授权同步 GitHub，并采用 DMG 作为唯一公开安装包。

## 问题

GitHub 公开版仍是 1.0.1，没有本机 1.1.0 的“默认隐藏全部桌面文件”功能。原有 ZIP 下载需要用户解压后自行判断怎样安装；同时提供多种安装格式会增加选择负担。

## 改了什么

- 将 1.1.0 的全量/指定隐藏、恢复保护和交接资料同步到公开源码。1.1.1 不修改隐藏/恢复核心逻辑，主要新增安装包装与发布检查。
- 新增 Universal 2 DMG，内含“桌面文件隐身.app”、指向 Applications 的快捷方式和中文安装说明。App 从全新临时构建目录产生，不复制已安装 App 或用户数据。
- 公开安装附件仅提供 DMG，README 顶部突出一个下载入口。GitHub 自动生成的源码 ZIP / tar.gz 明确标注为开发资料；本机兼容 ZIP 不上传。
- 打包版本升至 1.1.1 / build 5；DMG、ZIP 和校验文件按版本共同清理，只保留最新及倒数第二版。
- 隐私检查增加只读挂载 DMG 后扫描真实内容并卸载；只允许镜像根目录明确指向 `/Applications` 的快捷方式，不遍历它，其他链接仍拒绝。
- 新增四项临时目录测试，验证快捷方式限制、运行时记录/私密标记检出与分发包清理范围。GitHub 工作流同步运行这些检查。
- 构建明确使用 `-srcowners any -anyowners`，保持源卷所有权设置不变，避免不必要的管理员授权请求。
- 保留本机未公开开发历史，以公开 GitHub 身份在原远程基线上创建最终源码树的公开提交，不上传本机设备作者信息，也不强推旧公开历史。

## 验证

- 本机 arm64 原生核心测试 **54 项通过，0 失败**，均使用临时合成文件和布局替身。
- 包内容和清理规则测试 **4 项通过**；测试只处理临时目录，不需要挂载负向测试镜像。
- 双架构 App 构建、arm64 / x86_64 核对及严格签名检查通过。Intel compatibility packs 的现有警告不影响本次编译结果。
- DMG 完整性检查、只读挂载后版本/架构/签名核对及实际文件内容扫描通过，检查后卸载。
- 公开前核对源码无用户数据、绝对用户名路径或私有密钥；本机含设备作者信息的提交不进入公开历史。
- 本报告记录本地打包检查；远端原生检查结果、正式发布状态与下载校验值在 [v1.1.1 发行说明](https://github.com/Jayzengcodetrip/desktop-privacy/releases/tag/v1.1.1) 中提供。

## 没有验证

- 没有操作用户真实桌面、没有新增真实 Finder 全量隐藏/恢复实测，没有在实体 Intel Mac 或其他 macOS 版本上测试。
- 本次没有重新执行 1.1.0 的隔离 UI 点击流程；该版本的界面与核心代码保持不变，历史证据见对应报告。
- 没有模拟互联网下载隔离标记下的首次打开、首次权限授权或 Apple 公证验证。当前仍为 ad-hoc 签名，未 Developer ID 签名、未 Apple 公证。
- 没有替换用户正在使用的 1.1.0 App，也未迁移、删除或重写真实名单和恢复数据。

## 交付

- 公开安装包：`Desktop-Privacy-1.1.1-universal.dmg`。
- 本机产物：`dist/` 中保留 DMG、App、兼容 ZIP 和校验文件；源码归档只从已提交源码生成。
- 安装：打开 DMG，将 App 拖入 Applications；升级前先恢复旧版隐藏文件并退出。DMG 是安装包装，不是 Apple 签名或公证。
