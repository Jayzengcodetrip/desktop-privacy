# 桌面文件隐身 · Desktop Privacy

录屏或演示前，单击菜单栏眼睛，一键隐藏当前桌面全部文件和文件夹；再点一次，恢复这些文件及本次隐藏前的位置。也可以继续使用“仅隐藏指定文件”，保留其他桌面项目可用。

这是独立的 macOS 小工具，可配合你已有的录屏软件使用。隐藏全部无需先选文件；指定文件的名单由你自己添加，首次为空，不预置任何人的文件名单。

当前版本为 **v1.1.1**：菜单栏眼睛默认隐藏全部桌面文件，指定文件功能保留为独立入口；新增 DMG 安装包。两种模式共用恢复流程，手动名单不会被全量操作覆盖。

M 系列与 Intel 使用同一个安装包，无需选择芯片版本。打开 DMG，把“桌面文件隐身”拖入其中的 **Applications（应用程序）**，再从“应用程序”启动。详细说明见下方“安装与首次打开”。

## 使用方式

1. 打开应用，直接单击菜单栏眼睛，或点击“隐藏桌面全部文件”。无需添加名单。
2. 应用记录本次位置，再隐藏当前桌面全部可见文件和文件夹。
3. 录屏结束后再单击眼睛，恢复本次文件并核对位置；未完成时保留恢复记录，供再次尝试。
4. 只想隐藏部分文件时，右键眼睛选择“管理指定文件…”，添加桌面顶层项目，再点击“仅隐藏指定的…项”或名单窗口的隐藏按钮。

指定隐藏完成后，单击眼睛也会先恢复这批指定文件。两种模式不能叠加；恢复完成后，眼睛下一次仍默认隐藏全部。从名单移除项目只修改名单，不删除、移动或改名文件。正在隐藏或等待恢复时，应先完成恢复再编辑名单。

“全部”指点击时桌面上可见的普通文件和文件夹，不包含磁盘、外接设备等虚拟图标；原已隐藏的文件保持原状。隐藏期间新放到桌面的文件仍会显示，下次隐藏时纳入。遇到符号链接等不支持的项目，应用会明确提示并停止，不会悄悄漏掉后声称全部隐藏。

## 适用范围与位置保护

- 适合“排序方式 → 无”的手工摆放桌面。当前版本不支持“贴紧网格”或其他排序模式；文件夹内部结构保持不变。
- 每次隐藏都会重新保存位置，因此平时可以重新摆放文件，下次隐藏以新位置为准。
- 遇到自动排序、叠放或无法确认的布局状态，应用会拒绝继续操作，不替你改变桌面排序设置。
- 隐藏后如果更换显示器、调整分辨率或改变桌面显示设置，应用不会强行写回旧坐标。文件可能已恢复显示，但位置恢复仍会保留为待完成；还原原来的显示设置后再尝试恢复。
- 文件被移走、删除或替换等情况会触发检查。请保留恢复记录，并按应用提示处理。
- 升级后可以继续恢复旧版保存的指定文件会话；新版隐藏后请用新版完成恢复，再切换旧版。

隐藏使用文件的隐藏属性。**如果 Finder 开启了“显示隐藏文件”，这些项目仍可能被看到。** 这不是加密或访问控制，也不会隐藏已打开的文档窗口、通知或应用中的最近文件。正式录制前，请用短录屏检查实际画面。

## 系统与验证状态

编译目标是 **macOS 13 及以上**。发行包采用 **Universal 2**，将 `arm64` 与 `x86_64` 放在同一个应用中，供 Apple Silicon 和 Intel Mac 使用。Universal 二进制的含义见 [Apple 官方说明](https://developer.apple.com/documentation/apple-silicon/building-a-universal-macos-binary)。

架构打包、运行测试和真实桌面操作验证是不同的检查。当前测试证据与待验证平台见 [1.1.1 版本报告](版本报告/1.1.1%20DMG安装包与GitHub发布.md)；旧版证据保留在 [历史验证记录](docs/VERIFICATION.md)。请勿将最低编译版本理解为所有 macOS 版本均已实机验证。

本项目目前仅提供 macOS 应用。Windows 需要另行开发，当前没有 Windows 版本。

## 安装与首次打开

**升级前：先在旧版恢复隐藏的文件并退出，再替换 App；不要删除原有名单或恢复记录。**

1. 下载上方的 **DMG 安装包**，双击打开。
2. 把“桌面文件隐身.app”拖入同一窗口里的 **Applications（应用程序）**。
3. 从“应用程序”打开“桌面文件隐身”，然后推出安装磁盘。

[版本更新说明](https://github.com/Jayzengcodetrip/desktop-privacy/releases/latest) · [查看源码](https://github.com/Jayzengcodetrip/desktop-privacy)

下载页中的 **Source code (zip / tar.gz)** 是给开发者的源码，不是安装包。普通用户只需下载 DMG。

当前构建使用 **ad-hoc 签名**，没有 Apple Developer ID 证书，也没有经过 Apple 公证。ad-hoc 签名不代表 Apple 已验证开发者身份或检查过应用。

DMG 只是更直观的安装包装，不会消除系统对未公证应用的提醒。

如果 macOS 因无法验证开发者或公证状态而阻止打开，在确认下载来源及文件完整性后，可按 Apple 的标准流程操作：

1. 先尝试打开一次应用。
2. 打开“系统设置 → 隐私与安全性”，找到安全性区域的相关提示，选择“仍要打开”（Open Anyway）。系统版本不同，按钮顺序或文字可能略有区别。
3. 按系统提示再次确认打开；如果要求，输入登录密码。

这是为该应用设置例外，不需要关闭 Gatekeeper。本文不提供移除隔离属性或关闭系统安全检查的命令。如果提示应用已损坏或会危害电脑，请停止打开并重新核对来源。[Apple：在 Mac 上安全地打开 App](https://support.apple.com/en-us/102445)

首次使用时，macOS 可能要求访问桌面文件，以及允许应用控制 Finder。Finder 自动化权限用于读取、恢复并核对图标位置。详情见 [隐私说明](PRIVACY.md)。

## 开发

先读 [项目说明](AGENTS.md)、[决策记录](决策记录.md) 和 [接手开发提示词](项目交接/接手开发提示词.md)。本机正式目录为 `~/Projects/DesktopPrivacy`；使用其他 Agent 时，应关联完整本机项目目录。

需要 macOS、Python 3，以及可用的 Apple Swift 编译器和 macOS SDK（Xcode 或相应的 Command Line Tools）。在仓库根目录运行：

```sh
python3 scripts/build.py
bash scripts/test.sh
```

构建脚本负责两个架构的编译与合并。请以脚本输出及 [验证记录](docs/VERIFICATION.md) 为准，不要在自己的真实桌面上运行未知测试。参与开发前请阅读 [贡献指南](CONTRIBUTING.md)。

Bundle ID：`io.github.jayzengcodetrip.desktop-privacy`。

## 隐私与许可

应用没有遥测、账户或网络服务，不上传隐藏名单。名单和恢复所需的桌面元数据保存在本机。完整范围见 [PRIVACY.md](PRIVACY.md)。
