# 接手开发提示词

请接手“桌面文件隐身”的 Mac 通用版，工作目录为 `~/Projects/DesktopPrivacy`。

先阅读根目录 `AGENTS.md`、`决策记录.md` 和最新版本报告，再检查 Git 状态。`AGENTS.md` 是唯一项目说明书，其他 Agent 入口只指向它。

当前构建版本为 1.1.1 / build 5，原公开基线为 v1.0.1；正在使用的 App 为前一轮安装的 1.1.0。用户已授权将原个人版 App 备份后原位替换，旧个人版源码、名单和恢复记录仍独立保留，不可改动，也不要把任何运行时用户数据拷入仓库。

请根据本次用户需求开发。单击眼睛默认隐藏点击时全部可见顶层文件；右键菜单、主面板和名单窗口保留指定文件隐藏。两种模式互斥，眼睛优先恢复已有会话；全量不覆盖手动名单，不持续跟踪新增文件。每次隐藏捕获最新位置，恢复不影响本次目标以外文件。新记录 schema 2 绑定桌面身份，兼容旧 schema 1。不要改为 Finder 全局开关，不要擅自增加联网、文件移动或 Windows 功能。

默认只在本机提交，不推送远程。每次交付按项目说明升版本、生成带版本号的包、补决策与报告、仅保留最新两版分发包并提交中文 Git 记录。测试使用临时合成文件；真实 Finder 和用户桌面验证必须单独说明范围和结果。

用户已明确授权本次 1.1.1 GitHub 发布；公开安装包只有 DMG，GitHub 自动源码归档不是安装包。本机未公开提交含设备作者信息，不能直接 push 本机 main；按 AGENTS.md 的公开副本流程同步，确保最终受控源码树一致。

可用 `bash scripts/ui_preview.sh` 构建隔离界面预览，使用临时合成桌面及布局替身。它能验证真实 AppKit 按钮和菜单栏路径，不能证明真实 Finder 的图标消失或位置恢复。完成后先恢复并退出预览，再清理脚本输出的临时目录。
